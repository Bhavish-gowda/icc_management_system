● PROJECT OVERVIEW

ICC Cricket Management System

A comprehensive frontend demonstration of a real-world cricket analytics platform — designed for DBMS course project evaluation. Built with HTML, CSS, JavaScript & Bootstrap 5.

View Dashboard Browse Players

Key Features

Data Management
CRUD operations for players, countries, and matches with modal forms and live table updates.
Global Search
Real-time JavaScript search filtering across players, countries, and match data.
Analytics Dashboard
Performance statistics, batting & bowling leaderboards, ranking tables with trend indicators.
Fully Responsive
Adaptive layout for mobile, tablet, and desktop. Collapsible sidebar and hamburger menu.
Dark Mode Toggle
One-click theme switcher between the neon dark theme and a clean light mode.
11 Pages
Complete multi-page system: Dashboard, Countries, Players, Teams, Matches, Rankings + more.
